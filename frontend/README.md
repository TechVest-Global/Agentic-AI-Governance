# AegisGov AI Frontend

React + TypeScript + Vite prototype for an Enterprise GenAI Governance Engine.

## Stack

- React
- TypeScript
- Vite
- TailwindCSS
- lucide-react
- Recharts
- React Flow
- Zustand
- Mock data only

## Run

```bash
npm run dev
```

The Vite dev server defaults to `http://localhost:5173`.

## Structure

```text
src/components/layout
src/components/ui
src/pages
src/data
src/types
src/store
```
